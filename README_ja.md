# Knit Mini（yarnfriend）

**編み物の段数**と**毛糸在庫**をひとつの画面で管理できる、オフライン対応の小さなアプリです。  
UXの流れ、ローカル保存、PWAとしての軽量な挙動を検証するためのプロトタイプです。

## このプロジェクトについて
「シンプルなUX」「オフライン動作」「構造化データ管理」を学習した内容を踏まえ、簡単な形で実装しています。  
まだまだ改善の余地があるので、随時更新予定です。

## 主な機能
- **プロジェクト / 段数カウンター**
- プロジェクト作成と段数の増減
- +10 / -10 のクイック操作
- リセット・削除
- **毛糸在庫**
- 名前・色・ロット・素材・グラム数・メモの管理
- プロジェクトへの紐づけ / カスタム用途入力
- 写真の追加（圧縮してローカル保存）
- `+` / `-` / `=0` / 削除 / 写真削除 のクイック操作
- **オフライン対応（PWA）**
- Service Worker によるキャッシュ
- 初回読み込み後はネット無しでも動作

## 技術構成
- Vanilla HTML / CSS / JavaScript
- LocalStorage による保存
- Service Worker によるキャッシュ（PWA）

## 起動方法
静的アプリなのでビルド不要です。

1. リポジトリをクローン
2. `index.html` をブラウザで開く  
   - PWA / オフライン機能を試す場合はローカルサーバー推奨

例（ローカルサーバー）:
```bash
python -m http.server
```
`http://localhost:8000` にアクセス。
